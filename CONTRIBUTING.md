# Contributing

Thanks for helping improve AI Image Recognition Skill.

## Before opening a pull request

1. Describe the image-inspection problem your change solves.
2. Keep the original image files unmodified; write generated previews to a separate output directory.
3. Test with a small range of image formats and include the Python/Pillow versions used.
4. Clearly label heuristic results as estimates rather than guaranteed classifications.
5. Do not include private images or images containing personal metadata in public issues or pull requests.

## Bug reports

Please include:
- Operating system and Python version
- Pillow version (and NumPy version, if installed)
- Image format and dimensions
- The command you ran
- The relevant error or unexpected report field

If the image is sensitive, do not upload it. A minimal synthetic or redacted test case is preferred.

## Pull requests

Keep changes focused, update documentation when behavior changes, and explain how you tested the change.
